## โครงโฟลเดอร์ (จำแค่นี้พอ)

| โฟลเดอร์ | ใช้ทำอะไร |
| --- | --- |
| **`learn/`** | คู่มือไทย + ไฟล์ฝึก (เปิดอันนี้เป็นหลัก) |
| **`01_Day_...` ถึง `30_Day_...`** | ต้นฉบับ + starter / ข้อมูลโปรเจกต์ |
| **`data/`** | ไฟล์ข้อมูลประเทศ ฯลฯ |
| **`images/`** | รูปประกอบจากต้นฉบับ |

ไม่มีโฟลเดอร์ภาษาอื่นแล้ว — เหลือเฉพาะเส้นทางเรียนของคุณ

---

## วิธีเรียนวันละบท

1. เปิด `learn/XX_.../XX_day.md`
2. ลองตัวอย่างใน Browser Console (F12)
3. เขียนเองใน `learn/XX_.../practice.js`
4. วัน 21–30: เขียนโค้ดจริงในโฟลเดอร์ `XX_Day_.../*_starter`

**อย่าหาเฉลยจากเน็ต** — ติดแล้วถามทีละจุดจะจำได้กว่า
