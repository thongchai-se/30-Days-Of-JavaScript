# ตารางเรียน — เปิดอันนี้ทุกวัน

อ่านคู่มือ → เขียนใน `practice.js` → **ไม่มีเฉลย**

กลับ [หน้าแรก](../README.md)

## วิธีเรียน

1. เปิด `XX_day.md` ของวันนั้น
2. ลองตัวอย่างใน Console (F12)
3. เขียนเองใน `practice.js`
4. วัน 21–30 เขียนในโฟลเดอร์ `../XX_Day_.../*_starter` ของวันนั้น
