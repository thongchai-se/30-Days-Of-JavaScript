## วันนี้เรียนอะไร

วันนี้เป็น **โปรเจกต์รวมทักษะ**: DOM + event + คำนวณ  
ทำแอปคำนวณน้ำหนักวัตถุบนดาวเคราะห์ต่าง ๆ

## แนวทางทำ

1. เปิด [`24_day_starter`](../../24_Day_Project_solar_system/24_day_starter/)
2. ดู gif/วิดีโอในบทอังกฤษว่า UI ต้องเป็นยังไง
3. มี input น้ำหนักบนโลก + เลือกดาว
4. คำนวณน้ำหนักบนดาวนั้น (ใช้ค่า gravity ของแต่ละดาว)
5. แสดงผลบนหน้า

สูตรคร่าวๆ: `น้ำหนักบนดาว = มวล × แรงโน้มถ่วงของดาว`  
(ถ้าโจทย์ให้เป็นน้ำหนักบนโลก ต้องแปลงเป็นมวลก่อน: `มวล = น้ำหนัก / gโลก`)
